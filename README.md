# Жеребьёвка команд

Страница для деления зала на команды в первые 10 минут мероприятия.

**Открыть:** https://mlops-summer-day-2026.github.io/teams/

## Как делит

Не «все в кучу и перемешать» — так в одну команду попали бы три подписки Max,
а в другую ни одной, и половина зала осталась бы без возможности вайбкодить.
Раздача идёт слоями:

1. **Капитаны** — по одному Max на команду. Если Max меньше, чем команд,
   недостающих капитанов берём из Pro, потом из остальных
2. **Pro** раскидываются по кругу, чтобы в каждой команде был второй пилот
3. **Все остальные** — тоже по кругу, размер команд выравнивается сам

Жеребьёвка воспроизводимая: результат определяется сидом, который виден внизу
страницы и лежит в адресе. Один и тот же сид с тем же списком всегда даёт
тот же расклад — если вкладка закроется посреди мероприятия, состав вернётся
по ссылке.

## Откуда берётся список

Два пути, второй важнее.

**Файл в репозитории.** `participants.json` — основа, грузится при открытии.
Формат простой:

```json
[{ "name": "Юра Таран", "gh": "halfrollboy", "sub": "Max" }]
```

`sub` — это `Max`, `Pro` или пустая строка.

**Вставка на лету.** Внизу страницы панель «Список участников». Открываешь
[таблицу сбора](https://docs.google.com/spreadsheets/d/1GIsuqAtjAdVU7VJhHgqknojh20QKeWyHFNX_kUPFhts/edit),
выделяешь строки, копируешь, вставляешь, жмёшь «Применить список». Список ложится
в память браузера и переживает перезагрузку. Порядок колонок не важен: Max и Pro
распознаются по значению, а не по номеру столбца.

Так что перед мероприятием файл можно не трогать вовсе — достаточно вставить
свежую таблицу прямо на сцене. Кнопка «Вернуть сохранённый» откатывает к файлу.

## На всякий случай

- **«Скопировать состав»** кладёт расклад текстом в буфер — удобно отправить в общий чат
- **«Распечатать»** даёт чистую версию без кнопок и фона, по карточке на команду
- Страница работает без интернета, если открыть её локально: всё в одном файле
